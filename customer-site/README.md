# ゆうやけこやけ

静的な1ページ紹介サイトです。ローカル確認は `python3 -m http.server 4173` をこのディレクトリで実行し、`http://127.0.0.1:4173` を開いてください。

掲載している営業時間・定休日・住所は依頼者提供値です。公開前に店舗側の正式確認が必要です。

`index.html` の canonical は相対URL（`./`）です。静的な1ページをサイトルートへ公開する場合は、その公開URLへ解決されます。独自ドメインやサブディレクトリが確定したら、公開後の絶対URLへ置き換え、同じURLを `og:url` にも設定してください。
