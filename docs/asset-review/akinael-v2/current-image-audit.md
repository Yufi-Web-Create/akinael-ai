## 視覚シリーズとしての問題

- ヒーロー、美容、教室、地域サービスの4点が若〜中年女性、淡いベージュ系室内、下向きの視線に偏っています。飲食店写真も下向きで、全5写真の視線と静かな作業姿勢が単調です。
- 写真は全体に整いすぎ、生活ノイズや実際の接客相手が少ないため、地域の小規模事業者より生成系ストック写真の印象が先に立ちます。
- 美容と飲食は業種を識別できますが、教室はクラフト作業に見え、地域サービスはマッサージ店に限定して見えます。
- 原寸確認では、現行写真に直ちに不採用とするほど明白な余分な指や融合した食器は確認できませんでした。ただし、意味・多様性・クロップ耐性は不十分です。
- 現行の主要 PNG 8点は合計 12,868,860 bytes、約12.3 MiB です。トップページの img に loading=lazy はなく、1254px アバターも32〜54px用途へそのまま配信されています。

## マイページ画像の取り扱い

> [mypage-preview.png](../../../public/assets/photos/mypage-preview.png) は実在 UI を示す証拠画像であり、AI画像生成による再制作・補完・架空UI化の対象外です。

スマホ向けの「相談入力」「AIからの回答／進行」「結果・確認」の3クロップは、認証済みの実画面または安全なデモ環境から新しくキャプチャできるまで保留します。実施時は、個人情報、メールアドレス、顧客名、トークン、実案件データを除去し、実在する機能だけを使用します。現在の1600×1000画像を単純拡大・AI補完して作ることはしません。

## 結論

- 最優先は、PCとスマホを別構図にしたヒーロー差し替えです。現行横長1枚をモバイルで cover する方式では、顔の安全領域を確保できません。
- 業種別写真は、4:3マスターで顔、手、業種物品を中央80%へ置き、必要に応じて4:5モバイル版を用意する必要があります。
- 説明イラストとアバターは、写真とロゴに合う平面的な表現と用途別小サイズへ置き換える必要があります。
- ロゴは既存 SVG を維持します。
- マイページ画像はAI生成せず、安全な実UIキャプチャが可能になってから機能別クロップを制作します。
